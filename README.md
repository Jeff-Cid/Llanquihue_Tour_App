# Llanquihue Tour App

## Descripción
Programa en lenguaje Java que lee los tours de una agencia de turismo desde un archivo de texto (tours.txt), los guarda en un ArrayList, los muestra todos en la consola y además filtra los que cuestan más de $40.000.

## Estructura de las carpetas
- **model**: contiene la clase Tour, que guarda los datos de cada tour.
- **data**: contiene la clase GestorDatos, que lee el archivo y crea los tours.
- **ui**: contiene la clase Main, que muestra y filtra los tours.
- **resources**: contiene el archivo tours.txt con los datos de los tours.
- **README.md**: este archivo, con la explicación del proyecto.

## Cómo ejecutar
1. Abrir el proyecto en IntelliJ IDEA.
2. Abrir la clase Main (carpeta ui).
3. Presionar el botón verde de Run.
4. Se mostrará la lista completa de tours y luego los tours con precio
   superior a $40.000.
